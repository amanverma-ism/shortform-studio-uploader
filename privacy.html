Privacy Policy — Shortform Studio Uploader

Effective 17 November 2026.

Who uses it. This tool is used only by the owner of the YouTube channels Kalyug Wale and Boondi Tales, on the owner's own computer. It has no other users.

What it accesses. With the owner's permission through Google sign-in, it uses the YouTube Data API to upload the owner's own videos and to read and update the owner's own channels, videos, playlists and thumbnails. It does not access any other user's data.

What it stores. The sign-in token is stored only on the owner's computer. No YouTube data is sold, shared with third parties, or used for advertising. Nothing is collected from viewers.

Google services. Use of information received from Google APIs follows the Google API Services User Data Policy and the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

YouTube API Services. This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. YouTube data is handled under the Google Privacy Policy.

Data retention and deletion. The only data kept is the OAuth sign-in token, stored on the owner's computer. It is used only to upload and manage the owner's own videos and is never sent anywhere else. No YouTube API data (such as video statistics) is stored for longer than 30 days. Access can be revoked at any time at myaccount.google.com/permissions or through Google security settings; the local token is then deleted at once, and any remaining API data is deleted within 7 days.

Changes. Any change to this policy will be posted on this page with a new effective date.

Contact. Through the About page of either YouTube channel.
